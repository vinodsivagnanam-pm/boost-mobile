Troubleshoot Your Texts

Having Trouble Sending or Receiving Texts?

Make sure you’ve done these basic troubleshooting steps before continuing with any of the steps below.

  1. Make sure you’re dialing a 10-digit number to send SMS or MMS (multimedia) messages. If you’re trying to send an MMS, make sure you have data available on your plan.

  2. Check that any stored contact information includes a correct and up-to-date phone number or email address.

  3. Try the default messaging app. (Messages, Google Messages, Samsung Messages)

On Android If you’re using a third party messaging app, try using the default messaging app. If this resolves the issue, reach out to the developers for help with the third party app.

On iPhone If you’re using iMessage (the message bubble is blue), press and hold the bubble and try resending the message.

  1. Check that there are no device controls like spam blocking, contact blocking, or parental controls preventing messages.

  2. Disable all Do Not Disturb settings.

You can also use these detailed, step-by-step guides to troubleshoot your specific device.

If you continue to experience issues, contact Boost Customer Care.
